# CIVA

CIVA is a simple public platform designed to help people share public problems, discover useful discussions, support communities, and participate in peaceful civic activities.

## About

CIVA is a service of Robaar, a department of Alzia, under Boss Group.

## Main Features

- Public problem sharing
- Trending posts
- Community discovery
- Community protests
- Post support
- Comments
- Search
- Latest news
- Top creators
- Top leaders
- User, Creator and Leader accounts

## Account Types

### User
Can explore CIVA and participate in available activities.

### Creator
Can create and publish posts according to CIVA's rules.

### Leader
Can create and manage communities according to CIVA's rules.

## Design

CIVA follows a simple, clean and readable interface with a primary blue-and-white visual identity.

## Technology

The project is being developed with a lightweight web technology stack and is designed with security, simplicity and maintainability in mind.

## Status

CIVA is currently under development.
